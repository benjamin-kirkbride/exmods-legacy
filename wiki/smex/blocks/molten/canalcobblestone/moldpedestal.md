title: Molten Canal (Mold Pedestal), cobblestone

A canal cell with a stand on top: sneak right-click with a mold in hand to set it down, sneak
right-click again to take it back, and sprint right-click to toggle the pour. It holds only 50
units itself, plus whatever the mold on it takes, and closing the pour severs the run at this cell
so nothing fills up behind a closed pedestal. Built from cobblestone, cut from whatever rock the site provides. See [[Casting]] for filling and reading a
mold and [[Molten metal]] for the run feeding it.
