This is where a canal run begins: place one below a furnace tap's spout, one block out from the
face the tap points at, and everything else is laid out from it. It holds 200 units, the most of
any canal cell, and it also takes a hand pour straight from a crucible, which is the quickest way
to feed a short run with no furnace behind it. Built from cobblestone, cut from whatever rock the site provides. See [[Molten metal]] for how
distance from a start decides which way metal moves along the run.
